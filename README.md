# Demand Forecasting App 📈

A machine learning web app built with **Streamlit** and **XGBoost** that predicts product demand from business inputs.

## Features
- Interactive web interface to enter product details
- Predicts demand using a trained XGBoost model
- Handles categorical data with saved label encoders

## Input Features
- Price
- Discount (%)
- Inventory Level
- Promotion (0/1)
- Competitor Pricing
- Category

## Tech Stack
Python, Pandas, NumPy, XGBoost, Scikit-learn, Streamlit
